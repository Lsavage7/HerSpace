# HerSpace

HerSpace is a social support platform designed for women and girls to access trusted guidance, emotional safety, and real community support in one digital ecosystem.

## Core MVP Experience

- Guided sign-in and safety onboarding before community access.
- Life-stage support feed for teen years, early career, motherhood, and life resets.
- Trusted advice stream from verified experts.
- Moderated community circles for emotional and practical support.
- Safety-first product direction with clear moderation and trust controls.

## Tech Stack

- Expo + React Native
- JavaScript
- Lightweight local mock data (ready to replace with Firebase or another backend)

## Run Locally

```bash
npm install
npm run start
```

Then open the app in iOS simulator, Android emulator, or Expo Go.

## Suggested Next Features
